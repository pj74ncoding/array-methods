Includes()

✅ includes() – Checks if value exists.The includes() method in JavaScript is used to determine whether a string or an array contains a specified value. It returns true if the value is found, otherwise false.

const fruits = ["Banana", "Orange", "Apple", "Mango"];     fruits.includes("Mango"); // is true     fruits.includes("peach"); // is false

const numbers = [1, 2, 3, 4, 5];    console.log(numbers.includes(2)); // is true

const fruits = ["Banana", "Orange", "Apple", "Mango"];     let index = fruits.indexOf("Apple");

find()

✅The find() method in JavaScript is used to return the first element in an array that satisfies a provided testing function. If no elements satisfy the testing function, it returns undefined. The find() method executes a function for each array element until it finds one where the function returns a truthy value. It then returns that element and stops iterating through the array.

const findNumbers = [1, 25, 22, 23, 3, 77, 56, 2, 66];

function findNumber(value, index, array) {

return value > 22 ; }


let foundNumber = findNumbers.find(findNumber);

foundNumber is: 25 as it is the first element in the array that passes the test which is over 22


Find an object

const inventory = [ { name: "apples", quantity: 2 }, { name: "bananas", quantity: 0 }, { name: "cherries", quantity: 5 }, ];

const result = inventory.find(({ name }) => name === "cherries");    console.log(result); // Output: { name: 'cherries', quantity: 5 }

findLast()

✅ – Returns last element matching condition. The findLast() method in JavaScript iterates an array in reverse order and returns the value of the last element that satisfies a given testing function. If no element matches, it returns undefined.

const numbersArray = [1, 44, 2, 76, 55, 4337, 2445, 33, 22, 5];

const findLastNumber = numbersArray.findLast((num) => num > 2445);

console.log("findLastNumber", findLastNumber);

findLastIndex()

✅ – Returns index of last match.The findLastIndex() method in JavaScript iterates through an array in reverse order and returns the index of the last element that satisfies a provided testing function. If no elements satisfy the testing function, it returns -1.

search()

✅The search() method in JavaScript is used to search for a match between a regular expression and a string. It returns the index of the first match found in the string. If no match is found, it returns -1. This method is case-sensitive and does not accept a start position argument.
