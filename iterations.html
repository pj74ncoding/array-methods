Reduce()

✅ The reduce() method iterates over each element of the array, applying the reducer function to accumulate a result. The reducer function takes four arguments:

accumulator: The accumulated value previously returned in the last invocation of the callback, or the initial value if provided.

currentValue: The current element being processed in the array.

currentIndex: The index of the current element being processed in the array. array: The array reduce() was called upon.


forEach()

✅ Use forEach() when you only need to perform actions and don’t care about a return value. Side effects only.



Filter()

✅The filter() method in JavaScript is used to create a new array containing elements that pass a specific test implemented by a callback function. It does not modify the original array.
