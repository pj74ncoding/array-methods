Adding and removing elements

  • ✅push() – Add to end.
  • ✅pop() – Remove from end.
  • ✅unshift() – Add to start.
  • ✅shift() – Remove from start.
  • ✅splice() – Add/remove at specific index.
  • ✅slice() method returns selected elements in a new array. Negative numbers select from the end of the array.
  • ✅fill() – Replace elements with a static value.

fill()

The fill() method fills specified elements in an array with a value.

The fill() method overwrites the original array

Start and end position can be specified. If not, all elements will be filled.

Syntax - array.fill(value, start, end)

value: Required. The value to fill in.    start: Optional. The start index (position). Default is 0.    end: Optional. The stop index (position). Default is array length.

Example one

fill() fills specified elements in an array with a value.

Fill all array elements with "Kiwi":

fruits.fill("Kiwi")

const fruits = ["Banana", "Orange", "Apple", "Mango"];

document.getElementById("demo").innerHTML = fruits.fill("Kiwi");

//output   Kiwi,Kiwi,Kiwi,Kiwi

The fill() method is not supported in Internet Explorer.

Example Two

fill() fills specified elements in an array with a value.

Fill the last two array elements with "Kiwi":

fruits.fill("Kiwi",2,4)

const fruits = ["Banana", "Orange", "Apple", "Mango"];

document.getElementById("demo").innerHTML = fruits.fill("Kiwi",2,4);

//output   Banana,Orange,Kiwi,Kiwi

The fill() method is not supported in Internet Explorer.

Example Three

// Fill entire array - console.log([1, 2, 3].fill(4)); // [4, 4, 4]

// Fill from index 1 to end - console.log([1, 2, 3, 4].fill(5, 1)); // [1, 5, 5, 5]

// Fill from index 2 to 4 -console.log([1, 2, 3, 4].fill(0, 2, 4)); // [1, 2, 0, 0]

// Using negative indexe -console.log([1, 2, 3].fill(9, -2)); // [1, 9, 9]

// Creating an array with default values -console.log(Array(5).fill("X"));

// ["X", "X", "X", "X", "X"]

If the value is an object, all elements will reference the same object:

let arr = Array(3).fill({}); arr[0].name = "John"; console.log(arr);

// [{name: "John"}, {name: "John"}, {name: "John"}]
