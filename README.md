## Overview

### Motivation

I wanted to build an application to help me understand array methods. The application shows array methods all in one place and puts them into categories. The application also  gives explanations of each method with examples of code.

### Objective

Having a central database stops the need to search for examples. Having categories helps to identify which method you reqiure depending on the task you are doing. Having explanations helps to understand each method.

### Learning Outcomes

- Learnt there is a lot of things you can do with an array

## Project Features

- Explanations of each array method
- Buttons to link to different pages
- Array methods categorised into sections such as Mutable vs Immutable ,Adding & Removing Elements and Iteration & Transformation
- JavaScript files to show examples of how to use the array methods

## Installation

### Clone the Repository

```bash
git clone https://github.com/pj74ncoding/array-methods.git
cd array-methods

```

### Install Dependencies

Frontend:

```bash
cd array-methods
npm install
```

### Run Development Servers

Frontend:

```bash
npm start
```
