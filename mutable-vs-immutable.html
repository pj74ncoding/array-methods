Mutable vs Immutable

In JavaScript, the terms mutable and immutable describe whether a value can be changed after it’s created.

✅1. Mutable

Definition: Values that can be changed in place without creating a new reference.

Examples: Objects ({}) Arrays ([]) Functions

Behavior: When you modify them, the same reference in memory is updated.

Mutable example:

let person = { name: "Alice" };

let alias = person; // alias points to the same object

alias.name = "Bob";

console.log(person.name); // "Bob" — original object changed

❌ 2. Immutable

Definition: Values that cannot be changed once created.

Any "change" creates a new value instead of modifying the original.

Examples:

Primitive types:

  • String
  • Number
  • Boolean
  • null
  • undefined
  • Symbol
  • BigInt

Behavior: Modifying them returns a new value.

Immutable Example:

let greeting = "Hello";

let newGreeting = greeting.toUpperCase();

console.log(greeting); // "Hello" — original

unchanged console.log(newGreeting); // "HELLO" — new string created

✅ Tip: To make objects immutable, you can use:

const obj = Object.freeze({ name: "Alice" });

obj.name = "Bob"; // Fails silently in non-strict mode

console.log(obj.name); // "Alice"
