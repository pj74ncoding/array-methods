Array methods in catergories


1. Creation & Conversion

✅Array.of() – Creates a new array from arguments.

✅Array.from() – Creates an array from iterable or array-like objects.

✅Array() constructor – Creates a new array.

✅Spread syntax [...] – Copies or merges arrays.


2. Adding & Removing Elements

✅push() – Add to end.

✅pop() – Remove from end.

✅unshift() – Add to start.

✅shift() – Remove from start.

✅splice() – Add/remove at specific index.

✅slice() method returns selected elements in a new array.

✅fill() – Replace elements with a static value.


3. Searching & Finding

✅indexOf() – First index of a value.

✅lastIndexOf() – Last index of a value.

✅includes() – Checks if value exists.

✅find() – Returns first element matching condition.

✅findIndex() – Returns index of first match.

✅findLast() (ES2023) –

✅Returns last element matching condition.

✅findLastIndex() (ES2023) – Returns index of last match.

4. Iteration & Transformation

✅forEach() – Loop through elements.

✅map() – Transform each element into a new array.

✅flatMap() – Map and flatten one level.

✅filter() – Keep elements matching condition.

✅reduce() – Accumulate values into one result.

✅reduceRight() – Same as reduce() but from right to left.


5. Sorting & Reordering

✅sort() – Sort elements (default is lexicographic).

✅reverse() – Reverse order.

✅toReversed() (ES2023) – Returns reversed copy.

✅toSorted() (ES2023) –Returns sorted copy.


6. Flattening & Combining

✅concat() – Merge arrays.

✅flat() – Flatten nested arrays.

✅Spread syntax ... –Merge arrays inline.

7. String Conversion

✅join() – Join elements into a string.

✅split() – splits a string into an array of substrings, and returns the array:

✅toString() – Convert array to

✅comma-separated string.

✅toLocaleString() – Locale-aware string conversion.


8. Utility & Inspection

✅length – Number of elements.

✅isArray() – Check if value is an array.

✅entries() – Iterator of [index, value] pairs.

✅keys() – Iterator of indexes.

✅values() – Iterator of values.

✅every() – Check if all match condition.

✅some() – Check if at least one matches.

✅with() (ES2023) – Returns copy with element replaced at index.
