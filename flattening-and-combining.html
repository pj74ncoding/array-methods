Concat()

✅The concat() method in JavaScript is used to merge two or more arrays. This method does not change the existing arrays but instead returns a new array.The concat() method is a copying method. It does not alter the original arrays but returns a shallow copy that contains the same elements as the original arrays. You can also concatenate values directly to an array.

flat()

✅The flat() method in JavaScript is used to create a new array with all sub-array elements concatenated into it recursively up to the specified depth.The flat() method is a copying method that does not alter the original array but returns a shallow copy containing the same elements as the ones from the original array. It removes empty slots if the array being flattened is sparse.depth (optional): The depth level specifying how deep a nested array structure should be flattened. Defaults to 1.

Spread Operator ...

✅The spread operator (...) in JavaScript is a powerful feature that allows an iterable, such as an array or string, to be expanded in places where zero or more arguments or elements are expected. This operator is particularly useful for working with arrays and objects, making the code more concise and readable. While the spread operator is very useful, it is important to note that it performs a shallow copy. This means that nested objects or arrays will not be deeply copied
